# The Great AI Christmas Musical

## Description

"Code of Christmas" ist ein 25-minütiges Weihnachtsmusical, welches von den Kursteilnehmer*innen gepromptet, zusammengeschnitten, und dann beim dritten {un}easy Event gezeigt wurde.

## Details

KI-generierte Songs und Szenen zeigen die Geschichte von Lena, Jax und dem niedlichen Roboter Zeta auf ihrer Mission, Weihnachten vor einer mysteriösen KI-Bedrohung zu retten.
[Youtube-Link] (https://youtu.be/I_D93E7kouw?si=IwcF3i9Zu0xCFQEP)

## Verbose 

Das Skript wurde durch Prompts von einem groben Thema über einen Story-Überblick und ersten Songtexten bis hin zum vollständigen Drehbuch entwickelt. Für die Musik wurden hunderte Lieder mithilfe von Suno generiert. Die Dialoge wurden mit ElevenLabs mit text-to-speech erstellt, und alle Sounds im Anschluss manuell in Audacity komponiert. Für die visuelle Gestaltung wurden viele Stile ausprobiert, von denen einige besser funktionierten als andere. Hunderte von einigen Sekunden langen Clips wurden generiert, indem zuerst die Clip-Prompts mithilfe des Huggingface Chat LTX Prompt Helpers generiert wurden, diese in Flux.1 für ein Standbild und beide zusammen in LTX img2video eingespielt wurden.
Zuletzt wurde alles manuell zusammengeschnitten.
